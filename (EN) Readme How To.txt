---How To Run---

1. Prepare the dataset, Make sure the dataset file is available and follows the required format.

2. Train the model  
Go to Code > Train, run the training and tuning process for the algorithms. Models that have been tuned can be saved as .pkl files in the model folder.

3. Test the model, After training, proceed to Code > Test.
Perform testing on both descriptors and physiochemical properties.

4. Once testing is complete, run the consensus process on the selected algorithms.
The final output will display evaluation metrics such as Accuracy, AUC, F1, Sensitivity, Specificity, and more.
