---How To Run---

1. Siapkan dataset, Pastikan file dataset sudah tersedia dan sesuai format yang dibutuhkan.

2. Training model, Masuk ke folder Code > Train, lakukan proses training dan tuning algoritma.Model yang sudah selesai dituning dapat disimpan dalam bentuk file .pkl di folder model.

3. Setelah training, lanjutkan ke folder Code > Test.
Lakukan pengujian baik pada descriptor maupun pada data physiochemical.

4.Setelah testing selesai, lakukan proses consensus pada algoritma yang dipilih. Hasil akhir berupa metrik evaluasi (Accuracy, AUC, F1, Sensitivity, Specificity, dll) akan ditampilkan.
